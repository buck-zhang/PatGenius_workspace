Each folder contains tab separated text data which is used in this viewer.
Each element meaning is as follows.

===data_cpc_interleave===
CPC
Number of dot
Title (English)
CPC to IPC concordance
IPC part
Title (Japanese translation)
Number of simple patent families


===data_cpc_interleave_head===
CPC
Subsection title (English)


===data_cpc_wayaku===
CPC
Title (Japanese translation)


===data_ecla===
ECLA
Number of dot
Title (English)
ECLA to IPC concordance
Title (Japanese translation)
IPC part

* "IPC part" is used in normal version to identify the relevant IPC group. 


===data_fi===
FI
Number of dot
Number of dot in title 
Theme
FI to IPC concordance
Number of documents
Title (Japanese)
Title (English translation)


===data_fi_head===
FI
Subsection title (Japanese)
Subsection title (English translation)


===data_ipc===
IPC
Number of dot
Title (Japanese translation)
Title (English)
Number of simple patent families


===data_ipc_head===
FI
Subsection title (Japanese)
Subsection title (English translation)
