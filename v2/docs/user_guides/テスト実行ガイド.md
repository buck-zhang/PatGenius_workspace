## トラブルシューティング

### エラー1: ModuleNotFoundError

```
ModuleNotFoundError: No module named 'anthropic'
```

**解決方法:**
```bash
pip install 'anthropic[vertex]'
```

### エラー2: 認証エラー

```
google.auth.exceptions.DefaultCredentialsError
```

**解決方法:**
1. 認証ファイルのパスを確認
2. プロジェクトIDが正しいか確認

```bash
python -c "import json; print(json.load(open('../ttdc-in-house-dev-3e07247326cb.json'))['project_id'])"
```

### エラー3: Vertex AI APIが無効

```
google.api_core.exceptions.PermissionDenied: 403 Vertex AI API has not been used
```

**解決方法:**
Google Cloud ConsoleでVertex AI APIを有効化

### エラー4: JSON parse error

```
JSON_PARSE_ERROR: Expecting value
```

**解決方法:**
- Claudeのレスポンスを確認（`raw_response`フィールド）
- max_tokensを増やす
- プロンプトを調整

### 2. バッチ処理

複数ファイルを一括処理する場合：

```python
from pathlib import Path

analyzer = PatentStructureAnalyzer(
    credentials_path='../ttdc-in-house-dev-3e07247326cb.json'
)

# PDFファイルを一括処理
pdf_files = Path('/path/to/patents').glob('*.pdf')

for pdf_file in pdf_files:
    print(f"処理中: {pdf_file.name}")
    try:
        result = analyzer.analyze_file(pdf_file)
        print(f"  ✓ 成功: {len(result['構成要件'])} 個の構成要件")
    except Exception as e:
        print(f"  ✗ エラー: {e}")
```
