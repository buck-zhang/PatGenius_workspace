# JP2014089440A検索漏れ問題 - 改善提案レポート（化学系特許対応強化版）

**作成日**: 2025-12-05
**対象**: JP2014089440A vs JP2011032263A 検索漏れ問題
**目的**: 化学系特許の検索精度向上のためのプロンプト改善とロジック修正

---

## エグゼクティブサマリー

### 検索漏れの主要原因（確定）

1. **PatentFieldデータベースの分類情報欠落** (影響度: 80%)
   - JP2011032263はG03F7系IPCで検索してもヒットしない
   - データベース側の問題

2. **分類コード選定の偏り** (影響度: 15%)
   - C08F系（重合体）に偏重
   - C07C/C07D系（酸発生剤）が不足

3. **構成要件の詳細化・AND条件過多** (影響度: 5%)
   - 樹脂構造に細分化しすぎ
   - AND条件が多すぎて検索範囲が狭い

### 本提案の焦点

データベース側の問題（原因1）は即時解決困難のため、**原因2と3に対する改善策**を提示します。

## 1. 化学系特許特有の課題

### 1.1 技術的多様性の問題

レジスト組成物特許は、出願人によって強調する成分が異なります：

| アプローチ | 主要分類 | 強調成分 | 例 |
|---------|---------|---------|-----|
| **樹脂設計型** | C08F系 | フッ素含有樹脂重合体 | 本願JP2014089440A（住友化学） |
| **酸発生剤設計型** | C07C/C07D系 | 酸発生剤化合物（スルホニウム塩等） | ターゲットJP2011032263A（富士フイルム） |
| **プロセス最適化型** | G03F7系のみ | 製造方法・条件 | - |

**問題**: 現在の検索ロジックは本願の樹脂設計型アプローチに偏重し、酸発生剤設計型を逃している。

### 1.2 Fターム活用の不足

2025年時点で、日本の特許検索において**Fターム**は化学系検索の生命線です：

- 約3,400テーマコード、2,600以上にFターム分類が存在
- 物質の構造特徴、数値範囲、用途を多観点で分類
- **しかし**: 現在のシステムではFタームを十分に活用していない

参考: [日本の特許を特許分類から調べる | 国立国会図書館](https://ndlsearch.ndl.go.jp/rnavi/stm/post_398), [Fタームの分析で技術の用途開発に役立てる方法](https://marketing.techport.co.jp/archives/29573/)

### 1.3 化学物質名の表記揺れ

化学系特許では名称の表記揺れが激しい：

| カテゴリ | 例 |
|---------|-----|
| IUPAC名 vs 慣用名 | 2-プロパノン / アセトン / ジメチルケトン |
| 英語略語 | ポリ乳酸 / PLA / Polylactic acid |
| カタカナ表記 | ビニル / ビニール、メチル / メチール |

**問題**: 現在のキーワード生成プロンプトは、これらの表記揺れを網羅的にカバーしていない。

## 2. 現在の検索ロジックとプロンプトの問題点

### 2.1 構成要件分割の問題

**現在**: 樹脂構造に細分化（15個の詳細構成要件）
- 式(a4)構造単位
- 式(a5)構造単位
- フッ素含有飽和炭化水素基
- R4、環W3等

**問題**:
- 樹脂構造の詳細に偏重
- 酸発生剤、プロセス条件が不足
- ターゲット特許は酸発生剤中心のため検索漏れ

### 2.2 分類コード選定の偏り

**検索で使用されたFI分類（上位10件）**:

| 順位 | FIコード | タイトル | ターゲットとの関連 |
|-----|----------|---------|-----------------|
| 1 | G03F7/039601 | 化学増幅ポジ型レジスト | ○ 両方に関連 |
| 5 | **C08F212/14** | フッ素置換重合体 | **× ターゲットにない** |
| 7 | **C08F220/10** | エステル重合体 | **× ターゲットにない** |

**欠落していた分類コード**:
- C07C309/00（スルホン酸）
- C07C311/00（スルホン酸誘導体）
- C07C381/00（硫黄含有化合物）
- C07D215/00-417/00（複素環化合物）

### 2.3 現在のClaudeプロンプトの問題

#### 絞り込みプロンプト（patent_search_executor_per_component.py:494-592）

**良い点**:
- PatentField構文ルールが明確
- Top 20件サンプル分析を指示
- 化学系の検索戦略を記載（539-581行）

**問題点**:
1. **技術的多様性への言及が不足**
   - 樹脂 vs 酸発生剤の両アプローチへの配慮がない
   - C08F系 OR C07C/C07D系の併記指示がない

2. **Fターム活用の指示が弱い**
   - 「Fタームを優先的に利用」とあるが、具体的な戦略が不足
   - 数値範囲Fタームやテーマコードへの言及がない

3. **分類コードの包括性不足**
   - 「FI/IPC/CPC分類コードを効果的に組み合わせる」とあるが
   - 異なる技術アプローチの分類を併記する指示がない

#### キーワード拡張プロンプト（615-648行）

**良い点**:
- 同義語・類義語・上位概念を指示
- 英語カタカナ表記への配慮

**問題点**:
1. **化学物質名の表記揺れへの対応不足**
   - IUPAC名、慣用名、英語略語への明示的指示なし
   - マーカッシュ構造（R基等）への対応なし

2. **構造的特徴へのキーワード変換が弱い**
   - 「水酸基を2つ以上持つ」→Fタームへの変換指示なし
   - 誘導体、塩への対応が曖昧

## 3. 改善提案

### 3.1 構成要件抽出の改善（Claude分析時）

**現在**: 樹脂構造に偏重した15個の詳細構成要件

**改善案**: 3-5個の大括りカテゴリに統合

| カテゴリ | 含まれる要素 | 狙い |
|---------|-------------|------|
| **1. 樹脂成分** | 重合体、モノマー単位、酸不安定基 | C08F系をカバー |
| **2. 酸発生剤成分** | 光酸発生剤、スルホニウム塩、アニオン構造 | C07C/C07D系をカバー |
| **3. 添加剤成分** | クエンチャー、溶媒、界面活性剤 | 補助成分 |
| **4. プロセス条件** | 露光条件、現像条件、ベーク温度 | G03F7系プロセス |
| **5. 用途・効果** | 半導体製造、解像度、耐熱性 | 応用分野 |

**実装方法**: 構成要件抽出時のClaudeプロンプトに以下を追加

```
## 構成要件抽出の指針（レジスト組成物の場合）

レジスト組成物特許では、出願人によって強調する成分が異なります。
以下のカテゴリをバランス良く抽出してください：

1. **樹脂成分**: 重合体、モノマー単位、酸不安定基（C08F系）
2. **酸発生剤成分**: 光酸発生剤、スルホニウム塩、アニオン構造（C07C/C07D系）
3. **添加剤成分**: クエンチャー、溶媒、界面活性剤
4. **プロセス条件**: 露光、現像、ベーク（G03F7系）
5. **用途・効果**: 半導体製造、解像度、耐熱性

**重要**: 特定の成分（樹脂のみ、酸発生剤のみ）に偏らないこと。
```

### 3.2 分類コード選定の改善

#### A. 分類コード多様化の実装

**現在**: 本願の分類コードのみを使用

**改善案**: 技術分野ごとに「ドンピシャ + 関連分野」を併記

| 技術分野 | ドンピシャ分類 | 関連分野分類（追加） |
|---------|--------------|------------------|
| **レジスト組成物共通** | G03F7/039601, G03F7/004503A | G03F7/004, G03F7/20 |
| **樹脂設計アプローチ** | C08F220/18, C08F212/14 | C08F220/10-34（メタクリル酸エステル全般） |
| **酸発生剤設計アプローチ** | （追加）C07C381/12 | **C07C309/00, C07C311/00, C07D215/00-417/00** |
| **Fターム** | （強化）4J002系 | 4J100系（感光性樹脂組成物） |

#### B. 検索式への反映

**現在の検索式（構成要素1a）**:
```
(FI:G03F7/039601 OR FI:G03F7/004503A OR FI:C08F220/28)
+ (酸不安定基 OR 酸解離性基)
+ (構造単位 OR 繰り返し単位)
```

**改善案**:
```
(
  (FI:G03F7/039601 OR FI:G03F7/004503A)  # レジスト共通
  OR
  (FI:C08F220/18 OR FI:C08F212/14)       # 樹脂設計型
  OR
  (IPC:C07C309/00 OR IPC:C07C311/00 OR IPC:C07C381/00
   OR IPC:C07D215/00 OR IPC:C07D333/00)  # 酸発生剤設計型
)
+ (酸不安定基 OR 酸発生剤 OR スルホニウム OR 光酸発生)
```

**効果**: C08F系とC07C/C07D系の両アプローチをカバー

### 3.4 検索ロジックの修正

#### A. OR条件の拡充（2段階検索）

**提案**: Step 1のFI検索を2段階に拡張

**Step 1-1**: 樹脂設計型分類（C08F系）
```python
fi_query_resin = " OR ".join([f"FI:{fi}" for fi in resin_fi_codes])
# 例: FI:C08F220/18 OR FI:C08F212/14
```

**Step 1-2**: 酸発生剤設計型分類（C07C/C07D系）
```python
fi_query_acid = " OR ".join([f"IPC:{ipc}" for ipc in acid_ipc_codes])
# 例: IPC:C07C309/00 OR IPC:C07C311/00 OR IPC:C07D215/00
```

**Step 1-3**: 統合検索
```python
fi_query_combined = f"({fi_query_common}) OR ({fi_query_resin}) OR ({fi_query_acid})"
# 例: (FI:G03F7/039601) OR (FI:C08F220/18) OR (IPC:C07C309/00)
```

**効果**:
- 樹脂型と酸発生剤型の両アプローチをカバー
- どちらかに偏った特許も検索可能
