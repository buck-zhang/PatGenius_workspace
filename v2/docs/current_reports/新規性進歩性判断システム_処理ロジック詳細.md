## システム概要

### 目的

本願特許の**新規性**および**進歩性**を評価するため、検索結果特許との構成対比を自動実行し、以下を摘出する：

- **X文献**: 本願の全構成要素を**単独で**備える特許（新規性喪失のリスク）
- **Y文献**: **3件以内の組み合わせ**で全構成要素を備える特許群（進歩性欠如のリスク）

### 使用技術

| コンポーネント | 技術 |
|---------------|------|
| **AIモデル** | Gemini 3.0 Pro Preview |
| **推論設定** | Temperature=0.0（決定論的） |
| **Context Window** | 1M tokens |
| **特許データ取得** | PatentField API |
| **並列処理** | ThreadPoolExecutor (5並列) |
| **リトライ機構** | Exponential Backoff (3回) |

### 2.1 構成要素の分類

**2段階優先度システム**:

```python
# 優先度1: 全構成要素（最優先）
all_elements = set(elem['構成要素番号'] for elem in base_elements)
# 例: {'1a', '1b', '1c', '1d', '1e', '1f', '1f-1', '1f-2',
#      '2a', '2b', '3a', '3b', '3c', '4a', '4b',

# 優先度2: 独立請求項の構成要素（フォールバック）
independent_elements = set(
```

| **優先度1** | 全構成要素 | 真の新規性喪失リスク | 19要素 |
| **優先度2** | 独立請求項 | 基本的な技術思想の開示 | 8要素 |

### 2.2 X文献の摘出

**メソッド**: `extract_x_references(comparison_results, element_ids)`

**ロジック**:
```python
def extract_x_references(self, comparison_results, element_ids):
    """単独で全構成要素を備える特許を摘出"""
    x_references = []

    for result in comparison_results:
        patent_id = result.get('target_patent_id')
        element_comparisons = result.get('element_comparisons', [])

        # この特許が開示している要素を収集
        disclosed_elements = set()
        for elem in element_comparisons:
            if elem.get('is_disclosed', False) and elem['element_id'] in element_ids:
                disclosed_elements.add(elem['element_id'])

        # 全ての対象構成要素が開示されているか判定
        if disclosed_elements == element_ids:
            x_references.append(patent_id)

    return x_references
```

**判定条件**:
```
X文献 ⇔ disclosed_elements == element_ids
```

**例**:
```python
# 優先度1（全19要素）でのX文献判定
element_ids = {'1a', '1b', '1c', ..., '5d'}  # 19要素

# JP2013224028の場合
disclosed = {'1a', '1b', '1c', ..., '5d'}  # 19/19要素
disclosed == element_ids  # True → X文献

# JP2012040876の場合
disclosed = {'1a', '1b', '1c', '1d', '1e', '1f-1', '2b', '5a'}  # 8/19要素
disclosed == element_ids  # False → X文献ではない
```

### 2.3 Y文献の摘出

**メソッド**: `extract_y_references(comparison_results, element_ids, max_combination=3)`

**ロジック**:
```python
def extract_y_references(self, comparison_results, element_ids, max_combination=3):
    """組み合わせで全構成要素を備える特許群を摘出"""

    # 1. 各特許がどの要素を開示しているかマッピング
    patent_coverage = {}
    for result in comparison_results:
        patent_id = result.get('target_patent_id')
        disclosed = set(...)  # 開示要素の収集

        if disclosed:
            patent_coverage[patent_id] = disclosed

    # 2. k件の組み合わせを探索（k=1,2,3）
    y_references = []

    for k in range(1, max_combination + 1):
        for combo in combinations(patent_coverage.keys(), k):
            # 組み合わせでカバーされる要素の論理和
            combined_coverage = set()
            for patent_id in combo:
                combined_coverage |= patent_coverage[patent_id]

            # 全要素がカバーされているか
            if combined_coverage == element_ids:
                y_references.append({
                    "patents": list(combo),
                    "combination_count": k,
                    "coverage": {
                        pid: list(patent_coverage[pid])
                        for pid in combo
                    }
                })

    # 3. 組み合わせ数でソート
    y_references.sort(key=lambda x: x['combination_count'])

    return y_references
```

**判定条件**:
```
Y文献 ⇔ ∪(特許1の開示要素, 特許2の開示要素, ..., 特許nの開示要素) == element_ids
        where n ≤ 3
```

**例**:
```python
# 特許ごとの開示状況
patent_coverage = {
    'JP2013224028': {'1a', '1b', ..., '5d'},        # 19/19要素
    'JP2012040876': {'1a', '1b', '1c', '1d', '1e', '1f-1', '2b', '5a'},  # 8要素
    'JP2013086509': {'1a', '1c', '1d', '1f', '3b', '3c', ...},  # 18要素
    'JP2015048479': {'1e', '4b', '5a', '5b', ...},  # 13要素
    ...
}

# Y文献候補の探索
# 1件の組み合わせ
JP2013224028 単独 → 19/19 ✅ Y文献

# 2件の組み合わせ
JP2012040876 ∪ JP2013224028 → 19/19 ✅ Y文献
JP2013086509 ∪ JP2015048479 → 19/19 ✅ Y文献

# 3件の組み合わせ
JP2012040876 ∪ JP2013086509 ∪ JP2015048479 → 19/19 ✅ Y文献
```

**組み合わせ爆発の制御**:
- 最大組み合わせ数: 3件
- 理論的最大数: C(n,1) + C(n,2) + C(n,3)
- 例（n=10の場合）: 10 + 45 + 120 = 175通り
- 実用的な範囲内で全パターン探索

### 2.4 フォールバック戦略

**メソッド**: `_apply_fallback_strategy()`

**ロジック**:
```python
def _apply_fallback_strategy(self, x_all, y_all, x_independent, y_independent):
    """2段階優先度システム"""

    # 優先度1: 全構成要素で見つかった場合
    if x_all or y_all:
        return x_all, y_all, "priority_1_all_elements"

    # 優先度2: 独立請求項の構成要素で見つかった場合（フォールバック）
    if x_independent or y_independent:
        return x_independent, y_independent, "priority_2_independent_elements"

    # 何も見つからなかった場合
    return [], [], "no_matching_references"
```

**フォールバック順序**:
```
優先度1（全19要素）で探索
  ↓
  X文献 or Y文献が見つかった？
  ↓ Yes → 結果を採用
  ↓ No  → 優先度2へ
優先度2（独立請求項8要素）で探索
  ↓
  X文献 or Y文献が見つかった？
  ↓ Yes → 結果を採用
  ↓ No  → 該当なし
```

**実例**:
```
検索結果: 10件の特許

優先度1（全19要素）:
  X文献: 1件（JP2013224028）
  Y文献: 37件
  → ✅ 見つかった → priority_1_all_elements

優先度2（独立8要素）:
  （実行されない、優先度1で見つかったため）
```

## 判断基準とロジック

### 3.1 開示判断の基準

**Gemini 3.0 Proに指示している判断基準**:

#### 1. 明示的開示
```
条件: 請求項または明細書に同一または実質的に同一の構成が記載
例:
  本願: "50°超の接触角度"
  対象: "50度を超える接触角"
  → ✅ 明示的開示
```

#### 2. 図面による開示
```
条件: 図面に当該構成要素が視覚的に示されている
例:
  本願: "インクジェットプリントヘッド前面"
  対象: 図1に前面コーティングが図示
  → ✅ 図面による開示
```

#### 3. 当業者自明の開示
```
条件: 明細書の記載から当業者が容易に理解できる構成
例:
  本願: "疎油性低接着性被膜"
  対象: "撥油性低接着性コーティング"（用語の違い）
  → ✅ 当業者自明（機能的に同等）
```

#### 4. 実質的同一性の判断

**観点1: 機能・作用**
```
本願: "30°未満の滑走角度"
対象: "約30°未満の滑り角"
→ 同じ機能（低接着性）を示す → ✅ 実質的同一
```

**観点2: 構造・組成**
```
本願: エチルオキシドスペーサー（-CH2CH2O-）
対象: メチロール基（-CH2OH）
→ 化学構造が異なる → ❌ 実質的同一ではない
```

**観点3: 技術的意義**
```
本願: "150℃で30分間の第一硬化処理"（製造プロセス）
対象: "150℃で30分間の耐熱試験"（性能評価）
→ 技術的意義が異なる → ❌ 実質的同一ではない
```

### 3.2 Gemini 3.0 Proの高度な判断例

#### 例1: 数値範囲の包含関係

**本願**: 50°超の接触角度

**対象特許の記載**:
- "45°より大きい接触角"
- "実施形態によっては55°より大きい"

**Gemini 3.0 Proの判断**:
```
is_disclosed: true
reasoning: "対象特許は接触角が45°超、実施形態によっては55°超であることを
           開示しており、本願の「50°超」という数値範囲を包含しています。"
```

**ロジック**:
```
45° < x かつ 55° < y  （対象特許の範囲）
50° < z              （本願の範囲）

45° < 50° < 55°  → 50°超は45°超と55°超の範囲に包含
→ ✅ 実質的に開示されている
```

#### 例2: 化学構造の精緻な判断

**本願**: エチルオキシドスペーサー（-CH2CH2O-）を有する架橋材料

**対象特許の化学式**:
```
HOCH2CF2O(CF2CF2O)b(CF2O)cCF2CH2OH
      ↑                      ↑
  メチロール基              メチロール基
```

**Gemini 3.0 Proの判断**:
```
is_disclosed: false
reasoning: "段落0015に示される化学式はメチロール基（-CH2OH）を有しており、
           「エチルオキシドスペーサー（-CH2CH2O-）」を有する構成は
           明示的にも実質的にも開示されていません。
           化学構造上の明確な差異があります。"
```

**構造比較**:
```
本願のスペーサー:  -CH2-CH2-O-  (エチルオキシド)
                     ↑   ↑   ↑
                     C   C   O  (3原子)

対象のスペーサー:  -CH2-OH       (メチロール)
                     ↑   ↑
                     C   O  (2原子)

→ 原子数・結合様式が異なる → ❌ 別の化学構造
```

#### 例3: 技術的意義の区別

**本願**: 製造プロセスとしての硬化処理
- "150℃で30分〜2時間の第一硬化処理"
- "260℃で30分間の第二硬化処理"

**対象特許**: 耐熱試験条件
- "180℃〜320℃の範囲の温度に曝露後も性能維持"

**Gemini 3.0 Proの判断**:
```
is_disclosed: false
reasoning: "対象特許は耐熱性試験としての高温曝露については記載していますが、
           製造プロセスとしての「150℃で30分〜2時間の第一の硬化処理」
           という特定の硬化ステップについては開示がありません。"
```

**技術的意義の違い**:
```
本願のクレーム:
  → 製造方法（プロセス特許）
  → 目的: 被膜の形成・硬化
  → 技術的意義: 製造手順の規定

対象特許の記載:
  → 性能試験（物の特許の性能評価）
  → 目的: 耐熱性の確認
  → 技術的意義: 性能の証明

→ 用途・目的が異なる → ❌ 実質的同一ではない
```
