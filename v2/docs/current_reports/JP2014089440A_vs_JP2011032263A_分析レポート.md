### 4.2 検索結果の問題点

#### 全構成要素で目標範囲外

| 構成要素ID | 最終ヒット件数 | ステータス | 主な問題 |
|-----------|-------------|-----------|---------|
| 1a | 5,356件 | out_of_range | 過剰ヒット（目標300件） |
| 1a-2 | 6,768件 | out_of_range | 過剰ヒット |

**問題**:
- **過剰ヒット構成要素**: AND条件が不十分で絞り込めていない
- **0件構成要素**: 過度に詳細な条件で検索範囲が狭すぎる

### 4.3 検索式の例（構成要素1a）

```
(FI:G03F7/039601 OR FI:G03F7/004503A OR FI:C08F220/28 OR IPC:G03F7/039 OR CPC:G03F7/0392)
+ (酸不安定基 OR 酸解離性基 OR 酸脱離性基)
+ (構造単位 OR 繰り返し単位)
```

**問題点**:
1. **C08F系コードの使用**: `C08F220/28` はターゲット特許にない
2. **キーワードが汎用的**: 「酸不安定基」「構造単位」は多くのレジスト特許に共通
3. **Claude最適化の限界**: 5回の反復でも目標範囲に到達せず

## 5. 根本原因の特定

### 5.1 技術的焦点の相違

| 観点 | 本願特許 | ターゲット特許 |
|-----|---------|-------------|
| **主要成分の強調** | フッ素含有樹脂重合体 | 酸発生剤化合物 |
| **分類体系** | C08F系（高分子化学） | C07C/C07D系（有機化学） |
| **技術アプローチ** | 樹脂設計による性能向上 | 酸発生剤設計による性能向上 |
| **CPCコード** | 重合体・感光材料 | 有機化合物索引 |

### 5.2 構成要件分割の問題

本願特許の構成要件抽出は「式(a4)構造単位」「式(a5)構造単位」「フッ素含有飽和炭化水素基」など**樹脂構造に偏重**している。

しかし、ターゲット特許は**酸発生剤の化学構造（式(I)の化合物）**を中心に記載されており、樹脂の詳細構造は共通技術として扱われている可能性が高い。

### 5.3 検索式生成プロンプトの問題

現在のClaude検索式生成プロンプトは、**PatentField構文の正確性**に重点を置いているが、**技術的多様性**を考慮していない：

- 同じレジスト組成物でも、出願人によって強調する成分が異なる
- 富士フイルム: 酸発生剤化合物
- 住友化学: フッ素含有樹脂

---

## 6. 改善提案

### 6.1 構成要件分割の改善

#### 現状の問題
樹脂の詳細構造（式(a4), 式(a5), フッ素含有基など）に細分化しすぎている

#### 改善案
**技術的本質に基づく大括り化**:
1. **樹脂成分全般**: 酸不安定基を有する樹脂（詳細構造は問わない）
2. **酸発生剤全般**: スルホニウム塩、ヨードニウム塩など（化合物構造を広く）
3. **添加剤全般**: 式(I)の塩などの添加剤
4. **プロセス条件**: 露光・加熱・現像の条件

#### 具体的な構成要件再設計例

| 現在の構成要件 | 改善後の構成要件 |
|-------------|----------------|
| 1a: 式(a4)構造単位を含む樹脂 | **1: 酸不安定基含有樹脂（構造限定なし）** |
| 1a-2: R4がフッ素原子を有する飽和炭化水素基 | → 削除（詳細すぎる） |
| 1a-5: 環W3が炭素数6~10の炭化水素環 | → 削除（詳細すぎる） |
| 1b: 酸不安定基を有する構造単位を含む樹脂(A2) | → 1に統合 |
| 1c: 酸発生剤(B) | **2: 酸発生剤（化合物構造を広く）** |
| 1d: 式(II)で表される塩 | **3: 添加剤塩（式(II)限定せず）** |

### 6.2 特許分類コードの選定改善

#### 現状の問題
- ドンピシャ分類に **C08F系（重合体）** が含まれ、C07系を排除

#### 改善案
**多様な技術アプローチを包含する分類選定**:

| 分類系統 | 目的 | 使用推奨コード |
|---------|------|-------------|
| **G03F7系** | レジスト組成物全般 | G03F7/004, G03F7/039, G03F7/20（必須） |
| **C08F系** | 樹脂重合体アプローチ | C08F220/18, C08F212/14（オプション） |
| **C07C/C07D系** | 有機化合物アプローチ | C07C381/12, C07C309/00, C07D系（**追加必須**） |
| **H01L系** | 半導体製造用途 | H01L21/027（用途拡張） |

#### 具体的な改善FI/CPC選定

**追加すべきFI分類**:
- `C07C309/00` - スルホン酸（ターゲット特許のIPC）
- `C07C311/00` - スルホン酸誘導体（ターゲット特許のIPC）
- `C07D215/00`, `C07D307/00` - 複素環化合物（ターゲット特許のIPC）

**追加すべきCPC分類**:
- `C07C2601/12`, `C07C2601/14` - 有機化合物索引（ターゲット特許のCPC）
- `G03F7/0045`, `G03F7/0046` - 感光性材料（ターゲット特許のIPC）

### 6.3 検証用キーワードの生成改善

#### 現状の問題
- 「酸不安定基」「構造単位」など汎用的すぎる
- フッ素含有樹脂に特化したキーワードが多い

#### 改善案
**技術的多様性を考慮したキーワード生成**:

**樹脂成分**（本願アプローチ）:
- フッ素含有樹脂、ペルフルオロアルキル、含フッ素重合体
- アクリル樹脂、メタクリル樹脂、共重合体

**酸発生剤成分**（ターゲットアプローチ）:
- スルホニウム塩、ヨードニウム塩、オニウム塩
- 複素環化合物、芳香族スルホン酸、脂環式スルホン酸
- 酸発生剤、光酸発生剤、熱酸発生剤

**共通キーワード**:
- 化学増幅型レジスト、ネガ型レジスト、ポジ型レジスト
- 有機溶剤現像、アルカリ現像
- 露光、加熱、PEB（Post Exposure Bake）

### 6.4 Claude検索式生成プロンプトの改善

#### 現在のプロンプトの問題点
- PatentField構文の正確性に重点
- 技術的多様性の考慮が不足

#### 改善プロンプト案

```
# タスク: PatentField検索式の最適化（技術的多様性を考慮）

## 重要な原則
1. **技術的多様性**: 同じ技術分野でも、出願人によって強調する成分が異なる
   - 樹脂設計アプローチ: 高分子化学（C08F系）
   - 酸発生剤設計アプローチ: 有機化学（C07C/C07D系）
   - 両方のアプローチをカバーする検索式を生成すること

2. **分類コードの多様化**:
   - G03F7系（感光性材料）: 必須
   - C08F系（重合体）: 樹脂アプローチ用
   - C07C/C07D系（有機化合物）: 酸発生剤アプローチ用
   - 両系統を OR 条件で組み合わせること

3. **キーワードの包括性**:
   - 構成要素の詳細構造（式(a4), 式(II)など）を過度に限定しない
   - 技術的本質（酸不安定基、酸発生剤、添加剤塩など）に焦点を当てる
   - 同義語・類義語を広く含める

## 検索式の構築方針
- **Tier 1（必須）**: G03F7系分類 + 技術的本質キーワード
- **Tier 2（拡張）**: (C08F系 OR C07C/C07D系) + 成分別キーワード
- **最終検索式**: (Tier 1) OR (Tier 2)

## 出力形式
```json
{
  "search_query": "最適化された検索式",
  "reasoning": "技術的多様性を考慮したロジック説明",
  "coverage_analysis": "カバーする技術アプローチの説明"
}
```

## 8. 結論

### 8.1 主要な検索漏れ原因

1. **技術的焦点の相違を考慮していない**:
   - 本願: フッ素含有樹脂重合体（C08F系）
   - ターゲット: 酸発生剤化合物（C07C/C07D系）
   - **CPCコードが完全不一致**

2. **構成要件が詳細すぎる**:
   - 式(a4), 式(a5), フッ素含有基など、樹脂構造に細分化
   - ターゲット特許の技術的本質（酸発生剤）をカバーできない

3. **分類コード選定が偏っている**:
   - C08F系（重合体）に偏重
   - C07C/C07D系（有機化合物）が欠落

4. **キーワードが汎用的または特化的すぎる**:
   - 汎用: 「酸不安定基」→ 多くのレジスト特許に該当
   - 特化: 「ペルフルオロアルキル」→ フッ素含有樹脂に限定

### 8.2 優先改善事項

| 優先度 | 改善項目 | 期待効果 |
|-------|---------|---------|
| **最優先** | 分類コードにC07C/C07D系を追加 | ターゲット特許をカバー |
| **高** | 構成要件の大括り化（樹脂/酸発生剤/プロセス） | 技術的多様性を包含 |
| **高** | キーワード拡張（有機化合物・複素環） | 検索範囲の拡大 |
| **中** | Claude検索式生成プロンプト改善 | 技術的多様性の自動考慮 |
| **中** | 2段階検索戦略の導入 | Recall/Precisionのバランス |

### 8.3 次のアクション

1. C07C/C07D系分類コードを追加した検索の実行
2. 構成要件を3カテゴリに統合して再検索
3. JP2011032263Aがヒットすることを確認
4. 他のテストケース（test_006など）にも適用
