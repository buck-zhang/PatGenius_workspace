### Y文献選択ロジックの検証

#### 選択された組み合わせ

```json
{
  "primary_reference": "JP2013224028",
  "secondary_references": ["JP2013014763"],
  "combination_count": 2,
  "coverage": {
    "JP2013224028": [19要素],  // 主引例: 19要素を開示
    "JP2013014763": [3要素]     // 副引例: 3要素のみ開示
  }
}
```

#### 選択理由の検証

**スコアリング結果**（上位3件）:

| 順位 | 主引例 | 主引例カバレッジ | 副引例 | 副引例カバレッジ | 選択理由 |
|------|--------|----------------|--------|----------------|---------|
| **1** | **JP2013224028** | **19要素** | **JP2013014763** | **3要素** | ✅ **主引例のカバレッジ最大、副引例のカバレッジ最小** |
| 2 | JP2013224028 | 19要素 | JP2013052546 | 3要素 | 主引例同じ、副引例も同じ、特許番号で判断 |
| 3 | JP2013224028 | 19要素 | JP2011136559 | 5要素 | 主引例同じ、副引例カバレッジやや大 |

**選択ロジックの検証**:
- ✅ 主引例のカバレッジが最多（19要素）
- ✅ 副引例のカバレッジが最少（3要素）
- ✅ 実務上最も重要な組み合わせを選択

### 2. Y文献選択アルゴリズム

```python
def _select_representative_y_reference(y_combinations):
    """
    代表的なY文献組み合わせを選択

    選択基準:
    1. 主引例の開示要素数が最多
    2. 同数の場合、副引例の開示要素数が最少
    3. それでも同じ場合、主引例の特許番号が最も古い
    """
    scored_combinations = []

    for combo in y_combinations:
        primary_id = combo['primary_reference']
        primary_coverage = len(combo['coverage'][primary_id])

        # 副引例の合計カバレッジ
        secondary_coverage = sum(
            len(combo['coverage'][sec_id])
            for sec_id in combo['secondary_references']
        )

        # スコア: (主引例カバレッジ, -副引例カバレッジ, -主引例ID)
        score = (
            primary_coverage,
            -secondary_coverage,
            -int(''.join(filter(str.isdigit, primary_id)))
        )

        scored_combinations.append((score, combo))

    # スコアでソートして最良のものを選択
    scored_combinations.sort(key=lambda x: x[0], reverse=True)

    return scored_combinations[0][1]
```

**時間計算量**: O(n) （nはY文献組み合わせ数）
**空間計算量**: O(n)
