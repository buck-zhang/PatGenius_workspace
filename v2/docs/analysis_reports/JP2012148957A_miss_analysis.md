# 検索漏れ原因分析レポート: JP2012148957A

## エグゼクティブサマリー

**分析日**: 2025-11-30
**本願特許**: JP2014070017A (ガラス基板のエッチング切断方法)
**ターゲット特許**: JP2012148957A (携帯型電子機器用カバーガラスのガラス基板)
**検索結果**: **検索漏れ（最終結果に含まれず）**

### 重要な発見

1. **ターゲット特許は実際にはヒットしていた**
   - 構成要素1b（保護フィルム工程）のAttempt 6で1002件中287位として検出
   - しかし、「最良結果選択ロジック」により却下され、最終結果に含まれなかった

2. **根本原因は3つ**
   - ① 最良結果選択ロジックの欠陥
   - ② Claude反復最適化の過剰絞り込み（Over-refinement）
   - ③ 特許分類コードの不足

## 1. 詳細な原因分析

### 1.1 最良結果選択ロジックの問題

#### 問題の詳細

```

  - Claude利用時の目標範囲: 50-300件
  - Attempt 6: 1,002件 → OUT OF RANGE (多すぎる)
  - Attempt 7: 1件 → OUT OF RANGE (少なすぎる)
```

**問題点**:
- Attempt 6 (1,002件) は目標300件から702件オーバー

## 4. 改善提案

### 4.1 最良結果選択ロジックの改善

#### 現在のロジック（問題あり）

```python
def _select_best_attempt(iteration_attempts, target_min=50, target_max=300):
    # 範囲内がなければ、0件以外で目標範囲に最も近いもの
    candidates = [a for a in iteration_attempts if a['hits'] > 0]

    def distance_to_target(hits):
        if hits < target_min:
            return target_min - hits  # 50件未満の場合の距離
        else:
            return hits - target_max  # 300件超過の場合の距離

    best = min(candidates, key=lambda x: distance_to_target(x['hits']))
```

**問題**:
- 1件 (距離=49) vs 1,002件 (距離=702) → 1件が選択される
- しかし、1件は実質的に検索失敗

#### 改善案 1: **適応的閾値**

```python
def _select_best_attempt_improved(iteration_attempts, target_min=50, target_max=300):
    """
    改善された最良結果選択ロジック

    優先順位:
    1. 範囲内 (50-300) があれば最もヒット数が多いもの
    2. 範囲外の場合:
       a. 超過側 (>300) があれば、最も目標に近いもの（300件取得済みを優先）
       b. 不足側のみの場合、最も多いもの（ただし最低10件以上）
       c. 全て10件未満なら最後の試行
    """
    in_range = [a for a in iteration_attempts
                if target_min <= a['hits'] <= target_max]

    if in_range:
        return max(in_range, key=lambda x: x['hits'])

    # 範囲外の場合
    over_range = [a for a in iteration_attempts if a['hits'] > target_max]
    under_range = [a for a in iteration_attempts
                   if target_min > a['hits'] > 10]

    # 超過側を優先（300件は確実に取得できている）
    if over_range:
        return min(over_range, key=lambda x: x['hits'])  # 最小の超過

    # 不足側のみの場合
    if under_range:
        return max(under_range, key=lambda x: x['hits'])

    # 最終手段: 最後の試行
    return iteration_attempts[-1]
```

**メリット**:
- Attempt 6 (1,002件) が選択される
- 300件のTop結果を確実に取得可能
- 極端に少ない結果（1件）を回避


#### 改善案 1: **同義語・異表記の網羅的追加**

```python
def generate_keywords_with_synonyms(base_keywords):
    """
    同義語・異表記を自動生成

    Example:
      "保護フィルム" → ["保護フィルム", "保護膜", "保護フイルム", "保護layer"]
      "エッチング" → ["エッチング", "エッチング処理", "腐食", "化学研磨"]
    """
    synonym_rules = {
        'フィルム': ['フィルム', '膜', 'フイルム', 'film'],
        'エッチング': ['エッチング', 'エッチング処理', '腐食', '化学エッチング', 'ケミカルエッチング'],
        '保護': ['保護', '被覆', 'マスク', '耐エッチング'],
        'ガラス基板': ['ガラス基板', 'ガラス板', '硝子基板', 'ガラス材料', 'ガラスシート'],
    }

    expanded = []
    for kw in base_keywords:
        expanded.append(kw)
        for base, synonyms in synonym_rules.items():
            if base in kw:
                for syn in synonyms:
                    expanded.append(kw.replace(base, syn))

    return list(set(expanded))
```

```python
            print(f"⚠ Warning: ヒット数が急減 ({previous_hits} → {hits})")
            print(f"  前回の結果を採用します")
            return best_result

        # 最良結果を更新
        if hits >= 50:
            best_result = (refined_query, hits, patent_ids)

        previous_hits = hits

    # 5回終了後も範囲外なら、最良結果を返す (NEW!)
    if best_result and best_result[1] >= 50:
        print(f"⚠ 目標範囲外ですが、最良結果を採用: {best_result[1]}件")
        return best_result

    # 最終手段
    return refined_query, hits, patent_ids
```
