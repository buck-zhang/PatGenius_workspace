## 3. 検索戦略の改善

### 修正前の問題
```python
# Line 350（旧版）
use_keywords = len(other_element_ids) <= 2
# → other_element_idsが3個以上の時、キーワードを削除

# Line 377（旧版）
use_keywords = False  # 縮小時にキーワード削除
# → 逆効果：キーワードは絞り込みに有効
```

### 修正後の改善
```python
# 縮小戦略（ヒット数 > 300）
Attempt 1: 下位概念分類 + キーワード（use_keywords = True）
Attempt 2: 下位概念分類 + キーワード強化（use_keywords = True）
Attempt 3: 下位概念分類 + キーワード追加（use_keywords = True）
```

**原則**:
- **縮小時**: キーワードを維持して絞り込む
- **拡大時**: キーワードを削除して広げる

## 4. なぜJP2011171723Aが重要か

### 技術的類似性
1. **共通技術分野**: 酸化物半導体トランジスタ
2. **共通特性**: 極低オフ電流（100zA以下/μm）
3. **共通分類**: 同じFI/Fterm分類に該当

### 検索漏れ検証の理想的なケース
- **直接ファミリーではない**が**技術的に関連**
- 請求の範囲のキーワードマッチで捕捉可能
- 分類コードのみでは逃す可能性あり
- **キーワード+分類の組み合わせの重要性を証明**

### 結論

2. **全文検索 > CL限定**: より広範囲な検索が可能
3. **戦略的調整が重要**: キーワードの削除/維持を適切に判断
4. **JP2011171723Aの捕捉成功**: 修正版で検索漏れを防止
