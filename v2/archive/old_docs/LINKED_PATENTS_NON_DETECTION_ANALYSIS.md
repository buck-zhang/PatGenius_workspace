# 紐づき特許が検出されない原因の詳細分析

**作成日**: 2025年11月28日
**対象**: Test #9の紐づき特許4件（すべてフォトレジスト関連）
**検出率**: **0/4 = 0.0%**

## エグゼクティブサマリー

本願特許（JP2014089440）と同じフォトレジスト技術分野に属する紐づき特許4件が、現在の検索システムでまったく検出されていません。本分析では、その根本原因を特定し、改善策を提示します。

### 重要な発見

1. **キーワードの特異性問題** 🔴
   - 本願特許の検索に使用されるキーワードは、本願特許に特化した記号（式(a4)、式(a5)、R4など）
   - 紐づき特許は異なる式番号を使用（例: 式(I)、式(b1)、式(c1)など）
   - このため、同じ技術分野でもキーワードが一致せず検出されない

2. **FI分類コードの詳細度問題** 🔴
   - 本願特許の検索条件: G03F7/039601, G03F7/038601 など非常に詳細な下位分類
   - 紐づき特許: 同じG03F7系でも、異なる下位分類を持つ可能性
   - 詳細すぎる分類コードは、同じ技術分野の特許を除外する

3. **検索戦略の過剰最適化** 🔴
   - 現在の検索: (詳細FI分類) AND (本願固有キーワード)
   - この戦略は本願特許にピンポイントで当たるが、類似特許を除外する
   - 先行技術調査としては範囲が狭すぎる

### 3. 検索戦略の過剰最適化

#### 現在の検索クエリの構造

```
(FI:G03F7/039601 OR FI:G03F7/038601 OR FI:G03F7/004503A OR ...)
AND
(キーワード:"フッ素含有構造単位" OR キーワード:"式(a4)" OR キーワード:"R4" OR ...)
```

この戦略の問題点:

1. **AND条件の厳格性**
   - FI分類 **AND** キーワード の両方が一致しないと検出されない
   - どちらか一方だけ一致する特許は除外される

2. **詳細すぎる分類コード**
   - G03F7/039601という9桁の詳細コードは、本願特許にピンポイント
   - 同じフォトレジスト技術でも、わずかに異なる構造だと別コードになる

3. **固有すぎるキーワード**
   - 式(a4), R4, 式(a5)などは本願特許の明細書でのみ使用される記号
   - 同じ化学構造でも、他の特許は異なる記号を使用

#### 検索範囲の可視化

```
                          全フォトレジスト特許
    ┌───────────────────────────────────────────────┐
    │                                               │
    │      G03F7系（フォトレジスト全般）            │
    │    ┌─────────────────────────────┐           │
    │    │                             │           │
    │    │  G03F7/039xxx（レジスト成分）│           │
    │    │  ┌───────────────────┐     │           │
    │    │  │ G03F7/039601  │←本願   │           │
    │    │  │（本願特許のみ）│        │           │
    │    │  └───────────────────┘     │           │
    │    │                             │           │
    │    │  ← 紐づき特許（G03F7/039602など）      │
    │    │     はここに存在する可能性             │
    │    └─────────────────────────────┘           │
    │                                               │
    └───────────────────────────────────────────────┘
```

現在の検索は、最も内側の小さな円（G03F7/039601）のみをターゲットにしている。

## 根本原因のまとめ

### 原因1: キーワードの特異性（最重要）⭐⭐⭐

**問題**:
- 本願特許の明細書で定義された固有の記号（式(a4), 式(a5), R4, R5など）を検索キーワードとして使用
- これらの記号は他の特許文書には存在しない

**影響**:
- 同じ化学構造や機能を持つ特許でも、異なる記号を使用していれば検出されない
- 検出率: 0/4 = 0.0%

**例**:
```
本願特許   : "R4はフッ素原子を有する飽和炭化水素基"
紐づき特許A: "Xはペルフルオロアルキル基" ← 同じ構造、異なる記号
紐づき特許B: "式(1)で表されるフッ化アルキル基" ← 同じ構造、異なる式番号
```

---

### 原因2: FI分類の詳細度（重要）⭐⭐

**問題**:
- 9桁の非常に詳細なFI分類コード（G03F7/039601）を使用
- これは本願特許の特定の化学構造に対応する詳細分類

**影響**:
- 同じG03F7系（フォトレジスト）でも、わずかに異なる化学構造を持つ特許は別のFIコードになる
- 結果として、技術的に類似した特許が除外される

**例**:
```
G03F7/039601 - フッ素含有+脂環式構造（本願特許）
G03F7/039602 - フッ素含有+異なる構造   （紐づき特許の可能性）
G03F7/038xxx - 別の成分系統           （紐づき特許の可能性）
```

---

### 原因3: AND検索の厳格性（重要）⭐⭐

**問題**:
- (詳細FI) AND (固有キーワード) という厳格な検索式
- 両方の条件を満たす特許のみが検出される

**影響**:
- FIコードが一致してもキーワードが異なる特許は除外
- キーワードが一致してもFIコードが異なる特許は除外

## 推奨される改善策

### 改善策1: キーワード戦略の抜本的見直し（最優先）🎯

#### 現在の問題
```
NG: 式(a4), 式(a5), R4, R5 などの本願固有記号
```

#### 改善案
```
OK: 汎用的な技術キーワードを使用

A. 機能ベースのキーワード
   - レジスト組成物
   - 感放射線性樹脂組成物
   - 酸発生剤
   - 現像液溶解性
   - パターン形成

B. 化学構造の上位概念
   - フッ素含有化合物（式番号なし）
   - 脂環式構造（式番号なし）
   - スルホニウム塩
   - カチオン重合開始剤

C. 技術的課題・効果
   - 解像度向上
   - ラインエッジラフネス
   - 液浸露光
   - ドライエッチング耐性
```

**実装方法**:
- キーワード抽出プロンプトを修正
- 「式(xx)」のような本願固有の記号を除外
- 上位概念の技術用語を優先的に抽出

---

### 改善策2: FI分類の階層的使用（優先度高）🎯

#### 現在の問題
```
NG: G03F7/039601, G03F7/038601 などの9桁詳細分類
```

#### 改善案A: ワイルドカード検索
```
OK: G03F7/039. (上位6桁 + ワイルドカード)
OK: G03F7/038. (上位6桁 + ワイルドカード)
OK: G03F7/004. (上位6桁 + ワイルドカード)
```

#### 改善案B: 上位3桁の使用
```
OK: G03F7. (フォトレジスト全般)
```

**実装方法**:
```python
# 現在の分類コード抽出を修正
def extract_broader_fi_codes(fi_code):
    """
    G03F7/039601 → [G03F7/039., G03F7.]
    """
    if len(fi_code) >= 9:
        return [
            fi_code[:9],      # 元の詳細分類
            fi_code[:7] + '.',  # 上位6桁 + ワイルドカード
            fi_code[:5] + '.'   # 上位3桁 + ワイルドカード
        ]
```


## 結論

### 主要な問題点

1. **キーワードの特異性**（最重要）
   - 本願固有の記号（式(a4), R4など）では他の特許を検出できない
   - 改善策: 汎用的な技術用語を使用

2. **FI分類の詳細度**（重要）
   - 9桁の詳細分類は範囲が狭すぎる
   - 改善策: 上位階層やワイルドカードを使用

3. **検索戦略の過剰最適化**（重要）
   - AND条件が厳格すぎる
   - 改善策: 階層的検索やOR条件の導入

### 検出率0%の理由

```
本願特許の検索条件:
  FI:G03F7/039601 (本願のみ該当)
  AND
  キーワード:"式(a4)" (本願のみ使用)

紐づき特許:
  FI:G03F7/039602 (わずかに異なる)
  キーワード:"式(I)" (異なる記号)

結果: 両方の条件が一致しないため検出失敗
```

### 推奨される次のアクション

**優先度1**: キーワード戦略の変更
- キーワード抽出プロンプトを修正
- 本願固有記号を除外し、汎用技術用語を優先

**優先度2**: FI分類の階層的使用を実装
- ワイルドカード検索を実装
- 上位階層コードを併用

**優先度3**: 検証テストを実施
- FI:G03F7.のみで検索して紐づき特許が検出されるか確認
- 検出されれば、原因はキーワードとFI分類の詳細度であることが確定
