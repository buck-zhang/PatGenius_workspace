## 問題点と改善案

### 問題1: FI分類が広すぎる

**現象**: 多くの構成要素で56,000件以上ヒット

**原因**: FI分類コードが上位階層すぎる（例: B41J2/135）

**改善案**:
1. より詳細な下位階層のFI分類を使用
2. FI分類の階層レベルを自動調整
3. 複数の分類コードタイプ（FI + Fterm + IPC）の組み合わせ検索

### 問題2: キーワードの効果が限定的

**現象**: FI AND キーワードで2件など極端に減少

**原因**: キーワードが特定すぎる（「疎油性低接着性被膜」）

**改善案**:
1. キーワードの一般化レベルを調整
2. 部分一致検索の活用
3. シノニム（類義語）の追加

### 問題3: 成功率24%

**現象**: 50-300件範囲内に収まるのは6/25要素のみ

**原因**: FI分類とキーワードのバランス調整が必要

**改善案**:
1. 分類コードの粒度調整機能
2. キーワード数の動的調整
3. 検索式の複雑度を段階的に変更
