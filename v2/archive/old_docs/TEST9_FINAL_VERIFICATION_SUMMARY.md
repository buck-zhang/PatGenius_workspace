**問題**: テストデータに末尾「A」が付いていた

**解決**:
```python
def normalize_patent_number(patent_number: str) -> str:
    """末尾のAを除去"""
    pattern = r'^(JP\d+)A$'
    match = re.match(pattern, patent_number)
    if match:
        return match.group(1)
    return patent_number
```

## 原因分析

### なぜ紐づき特許を検出できなかったか

#### 可能性1: キーワードの違い

本願特許（JP2014089440）とキーワード検証機能で検出・修正されたキーワード:

**修正されたキーワード（MAJOR_ISSUES）**:
1. 式a5の検証問題
2. 式a4の検証問題
3. 酸発生剤の検証問題
4. R4のスペース問題
5. 有機スルホニウムの検証問題

これらのキーワードは本願特許に特化しているため、他のフォトレジスト特許（紐づき特許）を検出できない可能性がある。

#### 可能性2: 分類コードの範囲

使用された分類コード（ドンピシャFI上位10件）:
- G03F7/039601, G03F7/038601, G03F7/004503A, G03F7/004501
- C08F20/10, C08F220/10
- C07C381/12, C07C309/17
- C09K3/00K, C08F212/14

これらは本願特許の分類コードであり、紐づき特許が異なる詳細分類を持っている可能性がある。

#### 可能性3: 検索戦略の限界

現在の検索戦略:
```
(FI:G03F7/039601 OR FI:G03F7/038601 ...) AND (特定キーワード)
```

この戦略は本願特許の特徴に特化しており、同じG03F7系でも異なる下位分類や異なるキーワードを持つ特許を検出できない可能性がある。
