## 問題の本質

### Test #9で0件ヒットした原因

**根本原因**: 特許明細書特有の表現をそのまま検索キーワードとして使用

❌ **問題のあるキーワード例**:
```
式(a4)で表される構造単位
式(a5)で表される構造単位
式(II)で表される塩
a5構造単位
```

これらは**特定の特許文書内でのみ定義される記号表現**であり、PatentFieldなどの特許データベースには存在しません。

## 検証機能の動作原理

### 評価基準

#### ❌ **MAJOR_ISSUES（重大な問題）**
- 「式(XX)で表される」表現
- 特定の特許文書でのみ定義される記号表現
- 略語や記号のみの表現
- 否定表現で検索困難

#### ⚠️ **MINOR_ISSUES（軽微な問題）**
- やや抽象的だが検索可能
- 専門的だが一般的な用語

#### ✅ **OK（問題なし）**
- 一般的な技術用語
- 技術辞書に載っている用語
- 複数の同義語・類義語を含む

### 改善方針
1. 明細書特有の表現を一般的な技術用語に変換
2. 同義語・類義語を複数含める
3. 検索範囲を適度に広げる（狭すぎず、広すぎず）
4. 否定表現を肯定的な表現に変換
