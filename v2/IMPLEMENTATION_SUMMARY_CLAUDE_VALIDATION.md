### 2. `_select_best_attempt()` メソッドの改善 ✅

**場所**: `patent_search_executor_per_component.py` lines 833-903

**変更内容**:
- 最大ヒット数選択 → **距離ベース選択**に変更
- 目標範囲（50-300件）に最も近い試行を選択

**アルゴリズム**:
```python
def distance_to_target(hits):
    if hits < target_min:
        return target_min - hits  # 下回る場合
    elif hits > target_max:
        return hits - target_max  # 上回る場合
    else:
        return 0  # 範囲内
```

**選択優先順位**:
1. 目標範囲内（50-300件）→ 最もヒット数が多いもの
2. 目標範囲外 → 目標範囲に最も近いもの（距離で計算、0件除外）
3. 全て0件 → 最後の試行をそのまま返す

**例**:
- 旧ロジック: 10,221件を選択（最大ヒット数）
- 新ロジック: 428件を選択（距離128 vs 距離9,921）

**CRITICAL**: 以下の構文ルールを厳守してください。これらに違反すると検索エラーが発生します。

   - 正しい例: FI:H01L27/108 + トランジスタ
   - 誤った例: FI:H01L27/108 + CL:トランジスタ ← CL:は禁止
